🌱 Eco Campus Bot
It is a simple AI-powered assistant built to help students make better choices about waste and sustainability on campus.
Not sure where to throw something?
Wondering if it can be recycled?
Need to find an e-waste collection point?
Just ask. 💬
What it does
- 🗑️ Helps identify the right way to dispose of different types of waste
- ♻️ Provides simple recycling and sustainability guidance
- 📍 Helps students find relevant campus collection points
- 💬 Lets users ask questions naturally through a chatbot
- 🌱 Encourages small, practical eco-friendly habits

Why we built it?
Sustainability doesn't always require big changes.
Sometimes, it starts with something as simple as knowing which bin to use or where to take an old battery.
Eco Campus Bot brings that information into one easy place, making sustainable choices a little simpler for students.

How it works
Ask → Understand → Guide → Act 
The student asks a question, the bot understands what they need, checks the available campus information, and provides a clear answer or direction.

🛠️ Built With
- AI / Natural Language Processing
- Next.js (React 19),Tailwind CSS,shadcn/ui,Lucide React
- Next.js App Router (API Routes),Vercel Serverless
- Supabase
